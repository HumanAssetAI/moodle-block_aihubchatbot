# Changelog

## 1.3.3 — build 2026101502

- Stable release metadata and updated installation, licensing and support documentation.
- Complete Greek translation of all 74 plugin language strings alongside English.
- Moodle language strings for learner and administrator interfaces, including accessibility labels and window controls.
- Empty title and launcher label fields select translated defaults for each viewer; saved custom text remains intact.
- Floating panel title uses the translated iframe title string.

Includes the earlier labelled launcher, once-per-course automatic opening, desktop dragging/resizing, Expand / Restore, centred image cropping, system Manager/administrator configuration restrictions and floating-panel visibility fix.

No runtime behavior changed between the Greek preview build 2026101501 and this stable build. Previous local release packages are preserved separately.
